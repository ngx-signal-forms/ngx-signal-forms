# Common pitfalls and replacements

Quick lookup for toolkit mistakes, removed APIs, and renames.
Full contracts live in each owning surface guide.
For Angular-only rules, see [signal-forms.md](signal-forms.md).

## Symptom lookup

| Symptom or mistake                                                     | Fix                                                                                                                            | Owning guide                                                         |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| Importing `NgxFormField` or assistive components from root             | Import from `/form-field`, `/assistive`, `/headless`, `/vest`, or `/testing`. Never import internal `/core`.                   | [SKILL.md](../SKILL.md#task-routing)                                 |
| Passing `form()` snapshot to `[formTree]`                              | Pass the callable tree (`[formTree]="myForm"`), not `myForm()`.                                                                | [assistive/guide.md](../assistive/guide.md#ngxformfielderrorsummary) |
| Duplicate or conflicting `aria-invalid` / `aria-describedby`           | Let auto-ARIA manage them, or set `ngxSignalFormControlAria="manual"` on the control host.                                     | [core/guide.md](../core/guide.md#control-semantics-and-auto-aria)    |
| Missing `aria-required` or required marker on Zod / Standard Schema    | Call `requiredFromStandardSchema(path.field, Schema)` beside `validateStandardSchema()`.                                       | [core/guide.md](../core/guide.md#configuration-and-messages)         |
| Binding `tone="..."` on `ngx-form-field-error` panel                   | Remove `tone`; `presentation="panel"` routes alert vs status from the `[errors]` content.                                      | [assistive/guide.md](../assistive/guide.md#ngxformfielderror)        |
| Warnings ignore `strategy="on-submit"`                                 | Set `warningStrategy` or `defaultWarningStrategy`; warnings use an independent cascade.                                        | [core/guide.md](../core/guide.md#message-timing)                     |
| Checking `field().invalid()` to separate warnings from blocking errors | Use `splitByKind()`, `isWarningError()`, or `hasOnlyWarnings()`. Angular treats `warn:` as invalid.                            | [core/guide.md](../core/guide.md#warning-helpers)                    |
| Wrapper cannot link error or hint IDs                                  | Put a stable `id` on the bound control, or pass explicit `fieldName` on `ngx-form-field-wrapper`.                              | [form-field/guide.md](../form-field/guide.md#wrapper-usage)          |
| Adding `placeholder=" "` for `appearance="outline"`                    | Remove it; the outline label is a static caption and does not float.                                                           | [form-field/guide.md](../form-field/guide.md#wrapper-usage)          |
| Wrong layout or missing auto-ARIA on custom switch, slider, or widget  | Declare `ngxSignalFormControl` (and `ngxSignalFormControlAria="manual"` for nested library switches). Import toolkit in child. | [core/guide.md](../core/guide.md#control-semantics-and-auto-aria)    |
| Custom wrapper `[formField]` input throws `NG0201: FORM_FIELD`         | Name the custom wrapper's input `field` (not `formField`) and compose `NgxFieldIdentityProvider` from root.                    | [headless-composition.md](headless-composition.md#host-composition)  |
| Missing custom control import crashes at runtime with `NG01914`        | Add the control to `imports` and enable `"strictUnknownElements": true` (Angular 22.3+) to catch it as `NG8001`.               | [signal-forms.md](signal-forms.md#custom-controls)                   |
| Binding `<select multiple [formField]>` fails                          | `<select multiple>` is unsupported by `[formField]`; use boolean checkboxes or a custom `FormValueControl<string[]>`.          | [signal-forms.md](signal-forms.md#model-and-field-state)             |
| `'on-submit'` errors never show                                        | Add `ngxSignalForm` on `form[formRoot]`, or pass `submittedStatus` explicitly to `createErrorVisibility()`.                    | [core/guide.md](../core/guide.md#message-timing)                     |
| Test fails after typing in a touched `'on-touch'` field                | In v1.0.0, move focus (`await userEvent.tab()`) or submit before asserting a visible error.                                    | [testing/guide.md](../testing/guide.md#testing-message-timing)       |
| Dark mode ignores `.dark` class on toolkit components                  | Toolkit colors follow CSS `color-scheme` + `light-dark()`. Set `:root.dark { color-scheme: dark; }`.                           | [form-field/guide.md](../form-field/guide.md#wrapper-usage)          |
| Vest throws `"Vest field name ... does not resolve"` in dev mode       | Fix the typo after the valid prefix (for example `address.cityy` -> `address.city`). Virtual top-level names are allowed.      | [vest/guide.md](../vest/guide.md#field-name-resolution)              |
| Vest leaks state across SSR requests or hangs on `await runResult`     | Create suite + `createVestAdapter()` per SSR request; await `run.settled()` for manual runs.                                   | [vest/guide.md](../vest/guide.md#suite-lifecycle-and-async-caveats)  |

## Removed and non-public APIs

Authoritative upgrade steps live in the [crossed migration guides](../migrations/guide.md).
Quick replacement map for removed or internalized exports:

| Removed or non-public                                                                                                                                                     | Use instead                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `'manual'` strategy                                                                                                                                                       | `createErrorVisibility()` + manual signal                                                                            |
| `autoAria` config key                                                                                                                                                     | `ngxSignalFormAutoAriaDisabled`, `ngxSignalFormControlAria="manual"`, or control presets                             |
| `computeShowErrors()`, `createShowErrorsSignal()`, `createShowErrorsComputed()`, `showErrors()`, `shouldShowErrors()`, `shouldShowWarnings()`                             | `createErrorVisibility()` or `createWarningVisibility()`                                                             |
| `combineShowErrors()`                                                                                                                                                     | `computed(() => a() \|\| b())`                                                                                       |
| `resolveErrorDisplayStrategy()`, `resolveWarningStrategy()`, `resolveStrategyFromContext()`, `resolveWarningStrategyFromContext()`, `resolveSubmittedStatusFromContext()` | `createErrorVisibility()` or `createWarningVisibility()`                                                             |
| `getDefaultValidationMessage()`                                                                                                                                           | `resolveValidationErrorMessage()`                                                                                    |
| `canSubmit()`                                                                                                                                                             | `canSubmitWithWarnings()`                                                                                            |
| `isSubmitting()`                                                                                                                                                          | Angular `form().submitting()` for in-flight state; `submittedStatus()` from `ngxSignalForm` for history              |
| `fieldNameResolver`, `strictFieldResolution` config                                                                                                                       | Control `id` or explicit wrapper `fieldName` (strict by default)                                                     |
| `injectFormConfig()`                                                                                                                                                      | `inject(NGX_SIGNAL_FORMS_CONFIG)` or `injectFormContext()`                                                           |
| `injectFieldControl()`                                                                                                                                                    | Removed (no replacement)                                                                                             |
| `isFormFieldAppearance()`, `isFormFieldOrientation()`                                                                                                                     | Compare against literals or type with `FormFieldAppearance` / `FormFieldOrientation`                                 |
| `NgxSignalFormControlSemanticsDirective`                                                                                                                                  | `NgxSignalFormControl` (directive class); `NgxSignalFormControlSemantics` stays the interface                        |
| `readNgxSignalFormControlSemantics()`, `inferNgxSignalFormControlKind()`                                                                                                  | `resolveNgxSignalFormControlSemantics()`                                                                             |
| `NgxControlPresetRegistry`                                                                                                                                                | `inject(NGX_SIGNAL_FORM_CONTROL_PRESETS)` + `mergeNgxSignalFormControlPresets()`                                     |
| `NgxFieldIdentity.isControlVisible`, `setControlVisible`, `ControlVisibilitySignal`                                                                                       | `createControlVisibilitySignal()` or `isElementCssVisible()` in `earlyRead`                                          |
| `SignalLike`, `ReactiveOrStatic`                                                                                                                                          | `NgxSignalLike`, `NgxReactiveOrStatic`                                                                               |
| `NgxFormFieldNotification`                                                                                                                                                | `NgxFormFieldError` with `presentation="panel"` and `[errors]`                                                       |
| `NgxHeadlessNotification`, `NotificationStateSignals`, `ResolvedNotificationMessage`                                                                                      | `NgxHeadlessErrorState` with `[errorsOverride]`                                                                      |
| `NgxFormFieldErrorListStyle`                                                                                                                                              | `NgxFormFieldListStyle` from `/assistive`                                                                            |
| `NgxCharacterCountValue`                                                                                                                                                  | `CharacterCountValue` from `/headless`                                                                               |
| `CharacterCountResult`, `CharacterCountStateSignals`                                                                                                                      | `CharacterCountState` from `/headless`                                                                               |
| `ErrorSummaryEntryData`                                                                                                                                                   | `ErrorSummaryEntry` from `/headless`                                                                                 |
| `summarizeFieldOptionality()`                                                                                                                                             | `createFieldOptionalitySummary()` from `/headless`                                                                   |
| `readFieldFlag()`                                                                                                                                                         | `field().invalid()` and sibling signals, or `createFieldStateFlags()`                                                |
| `readErrors()`                                                                                                                                                            | `field().errorSummary()` for subtrees, or `createErrorState()` / `readDirectErrors()` for one field                  |
| `toErrorSummaryEntry()`, `resolveFieldNameFromError()`, `focusBoundControlFromError()`                                                                                    | `createErrorSummaryEntries()` (entries provide `fieldName`, `focus()`, and `canFocus`)                               |
| `findAlertContaining()` from `/testing`                                                                                                                                   | Query `[role="alert"]` by text in the spec ([testing/guide.md](../testing/guide.md#testing-rules-for-rc17-behavior)) |
| `toHintDescriptors()`, `createErrorRendererInputs()`, `resolveUnionInput()`                                                                                               | Inline the `computed()` or union unwrap ([headless-composition.md](headless-composition.md))                         |
| `--ngx-signal-form-notification-*` CSS tokens                                                                                                                             | `--ngx-signal-form-error-panel-*` and `--ngx-signal-form-warning-panel-*`                                            |

## Renamed appearances

| Old                    | New                     | Note                                                                                 |
| ---------------------- | ----------------------- | ------------------------------------------------------------------------------------ |
| `appearance="stacked"` | `appearance="standard"` | Control layout `'stacked'` (`NgxSignalFormControlLayout`) is separate and unchanged. |
| `appearance="bare"`    | `appearance="plain"`    | Minimal wrapper chrome that keeps projected control styles intact.                   |
