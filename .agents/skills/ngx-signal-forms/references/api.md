# Toolkit API source index

Use this index to locate exports and contracts, not as a cached declaration file.
Check the consumer's installed version first (see [sources.md](sources.md)).
The guidance baseline is Angular 22.3; inspect installed peer ranges and declarations rather than assuming a patch version.

## Export authority

For an installed package, read its `package.json` `exports` map and follow the entry's `types` target to shipped `.d.ts` declarations.
Source files can contain `@internal` members stripped from published declarations.

For deeper lookup, start from these online public barrels and READMEs:

`@ngx-signal-forms/toolkit/core` is internal (a build-time sibling entry excluded from published exports).
Use the root barrel for public root exports, and use `provideErrorMessages()` / `provideFieldLabels()` rather than internal registry tokens.

`@ngx-signal-forms/debugger` is repository-internal and not published on npm.
For maintenance inside the toolkit repo, read its [README](https://github.com/ngx-signal-forms/ngx-signal-forms/blob/main/packages/demo/debugger/README.md) and [barrel](https://github.com/ngx-signal-forms/ngx-signal-forms/blob/main/packages/demo/debugger/src/index.ts).
